# Security

Write to **support@stillwarddisplay.com** with "Security" in the subject if you
find a way to make Stillward Display, a file it reads (a style, a look, a
pointer set, a widget, an icon set, an activity or a setup) or a Workshop item
do something it should not: run code, read or write outside its own folders,
reach the network, or leave a change behind on the PC.

Please do not open a public issue for it. You will get an answer within a few
days, and the fix goes out as an ordinary Steam update, listed in the
[releases](https://github.com/ayokiru/stillward-display/releases).
