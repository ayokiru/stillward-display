# Contributing

The program's source is private, so there are no pull requests for code. There
is still plenty to bring.

## Make something for the Workshop

Styles, taskbar looks, pointer sets, widgets, icon sets, island activities and
setups are all made by people who use the program. Start in
[`creators/`](creators/), where the formats, examples and templates are. Show
what you made in
[Discussions → Show and tell](https://github.com/ayokiru/stillward-display/discussions/categories/show-and-tell).

## Improve the formats' documentation

`creators/` is open for pull requests: a clearer description in a schema, a
better example, a mistake in the reference. A schema change reaches the site
in the same release. The program decides what a file may hold, so a change
that adds a field the program does not read waits for the program.

## Report a bug

Use the [bug form](https://github.com/ayokiru/stillward-display/issues/new?template=bug_report.yml)
with the diagnostic report from the program (Diagnostics → Run the diagnostic →
Copy report). One bug per issue.

## Suggest an idea

Open a thread in
[Ideas](https://github.com/ayokiru/stillward-display/discussions/categories/ideas).
Describe the moment it gets in your way, and how you deal with it now.

## Translations

The program and the site speak 30 languages. If a word in yours reads wrong,
open an issue with the page, the words you see and the words you would expect.
